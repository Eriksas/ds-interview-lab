CUPED 方差缩减

AB 实验 · 面试频率中 · 约 20 分钟

1一句话直觉

一个用户实验期看得多，很大程度是因为他本来就看得多。CUPED（Controlled-experiment Using Pre-Experiment Data，用实验前数据做调整）先把“本来就有的差异”扣掉，剩下的噪声小了，同样的样本更容易测出效果。

2交互实验 模拟

模拟指标：人均观看时长（分钟），实验前和实验期的标准差都是 20 分钟。实验组真实多看 τ 分钟。

④ 相关系数和省下的样本

默认 ρ=0.7、每组 500 人、τ=2 分钟：不调整和 CUPED 的功效各约多少？
理论功效：不调整约 35%，CUPED 约 60%（重复 4,000 次模拟为 36% 和 59%）。要达到 80% 功效，每组样本从 1,570 降到 801，几乎省一半，因为 1−0.7²=0.51。
把 ρ 拖到 0.5，方差减少多少？再拖到 0.9 呢？
ρ=0.5 时只减少 25%（剩 1−0.25=75%），所需样本 1,178；ρ=0.9 时减少 81%，所需样本只要 299。降幅是 ρ²，不是 ρ：相关系数要比较高，CUPED 才划算。
把 τ 拖到 0（A/A），看图 ③ 里 CUPED 估计的中心在哪里？
两条分布都以 0 为中心，显著比例都约 5%。CUPED 只让分布变窄，不移动中心：随机实验里不调整也是无偏的，CUPED 的作用是降方差。

3关键公式

Y_{cv}=Y-\theta\,(X-\bar X),\qquad \theta=\frac{\mathrm{Cov}(X,Y)}{\mathrm{Var}(X)}

X 是实验前的同一指标（或任何不受实验影响的变量）。θ 就是 Y 对 X 回归的斜率，用两组合并的数据估计。

\mathrm{Var}(Y_{cv})=\mathrm{Var}(Y)\,(1-\rho^2)

方差只剩 1−ρ²，所需样本量也按这个比例减少；标准误变成原来的 √(1−ρ²)。

E\big[\bar Y_{cv,T}-\bar Y_{cv,C}\big]=E\big[\bar Y_T-\bar Y_C\big]-\theta\,E\big[\bar X_T-\bar X_C\big]=\tau

随机分组下两组实验前的均值期望相同，调整项的期望是 0，所以估计仍然无偏。

Y_i=\alpha+\tau\,T_i+\theta\,X_i+\varepsilon_i

CUPED 和“回归里加实验前协变量”（ANCOVA，协方差分析）基本等价。用 Stata 写就是 reg y treat x_pre, vce(robust)，treat 的系数就是效应。多个协变量就一起放进回归。

4面试口述版（30 秒）

CUPED 用实验前的数据降低方差。做法是 Y_cv = Y − θ(X − X̄)，X 通常是同一指标在实验前的值，θ 是 Y 对 X 的回归斜率。调整后方差变成原来的 1−ρ²，ρ 是前后指标的相关系数，比如 ρ=0.7 时方差减少约一半，同样功效下样本量也省一半。因为是随机实验，两组 X 的期望相同，调整不会引入偏差，估计仍然无偏，它的作用只是降方差。要注意协变量必须不受实验影响，一般只用实验开始前的数据；新用户没有历史数据时可以用其他实验前特征或填补。它本质上就是回归里加了实验前协变量。

5常见误区

  • ✗ “加协变量是为了消除两组的偏差，不加就有偏”。
    ✓ 随机实验里不加协变量也是无偏的（图 ③ 两条分布中心相同）。CUPED 的作用是降方差、提高功效。
  • ✗ “ρ=0.5 时方差减半”。
    ✓ 方差减少的比例是 ρ²：ρ=0.5 只减少 25%，ρ=0.7 才减少约一半。
  • ✗ “随便挑一个和结果相关的变量都能当协变量”。
    ✓ 协变量必须不受实验影响，一般只用实验开始前的数据。用实验期间的变量（比如实验期活跃天数）做调整，会把一部分真实效应也扣掉，引入偏差。
  • ✗ “CUPED 只能用于连续指标”。
    ✓ 0/1 指标（转化率、购买率）同样可以，回归调整对它们一样成立；有的实验平台不支持，是工程实现的限制。
  • ✗ 把 θ 说成“k 值”或“修正系数随便取”。
    ✓ θ 是 Cov(X,Y)/Var(X)，也就是回归斜率；这个取值正好让调整后的方差最小。

6自测题

7和 X5 项目的联系

  • 项目用实验前交易次数做 CUPED：它和购买的相关系数平方是 0.127，所以方差减少 12.7%，等效样本量 ×1.15。相关性一般，所以收益有限，这正好对应“降幅是 ρ²”。
  • 把 7 个实验前指标一起放进回归调整，等效样本量 ×1.21，最小可检测效应从 0.61 降到 0.55 个百分点。
  • 坏控制变量：客户表里的“首次兑换积分日期”有一部分发生在短信之后，实验组“截止日后才首次兑换”的比例比对照组高 0.39 个百分点（p=0.006），说明它受短信影响，不能当协变量。这是“协变量必须不受实验影响”的真实例子。
  • 购买是 0/1 指标，照样能做 CUPED，这也回答了“二值指标能不能用 CUPED”。
